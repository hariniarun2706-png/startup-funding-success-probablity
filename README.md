# Startup Funding Success Probability Analysis

## Project Overview

This project analyzes startup funding success using statistical analysis and probability concepts. The objective is to identify the factors influencing funding success through descriptive statistics, probability analysis, visualization, and hypothesis testing.

## Objectives

* Analyze startup funding data.
* Perform descriptive statistical analysis.
* Calculate funding probabilities.
* Visualize relationships using graphs.
* Perform Chi-Square hypothesis testing.
* Generate business insights and recommendations.

## Tools and Technologies

* Python
* Pandas
* Matplotlib
* Seaborn
* SciPy
* Jupyter Notebook

## Dataset

The dataset contains 4,999 startup records with the following features:

* Team Size
* Founder Experience
* Startup Age
* Industry
* City
* Funding Goal
* Funding Raised
* Funding Success

## Project Files

* `dataset_synthetic.csv` – Dataset
* `t3.py` – Dataset generation
* `t4.ipynb` – Main analysis notebook
* `probability_report.pdf` – Project report

## Key Findings

* Overall funding success rate: **58.99%**
* Founder experience slightly improves funding probability.
* AI startups showed approximately **58.1%** funding success.
* Industry differences were not statistically significant based on the Chi-Square test.
* High Growth startups achieved the highest success rate.

## Conclusion

This project demonstrates how statistical analysis and probability techniques can be applied to understand startup funding success and support data-driven decision-making.
